## 💻 Running Locally

You can open `index.html` directly in any web browser, or serve it using Python or Node:

### Using Python:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.

### Using Node / npx:
```bash
npx serve .
```

## 🌐 Free Deployment Guide

### Deploy to Netlify (Drag & Drop):
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `bhavyanand-portfolio` folder.
3. Netlify will deploy your site instantly with a live URL!
4. Go to **Site Settings > Change Site Name** to pick a custom subdomain (e.g. `bhavyanandreddy.netlify.app`).

### Deploy to GitHub Pages:
1. Initialize a git repository and push to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for G.Bhavyanand Reddy portfolio"
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. In GitHub repository settings, go to **Pages** > Select `main` branch > Click **Save**.
